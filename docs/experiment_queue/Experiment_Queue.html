উৎস: Astra R7 §3-4

খরচ~18-26 u (সব বা শুধু দরকারি ~400 neuron); +7-10% util
পাস করার শর্তraw MSE >7-9% কমতে হবে (নইলে লোকসান)
পরের ধাপEnd-to-end test চলছে (a7_kernel_e2e.py, দুই network)। পাস করলে: FLOP-মাপা implementation -> Kaggle 10/100 MLP।
