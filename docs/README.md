# Documentation

* `ARC_WhestBench_2026_Complete_Notes.pdf` - the working handbook (Parts A-K): challenge rules and scoring, the starter kit,
  the dataset, the reference paper, the full Phase-2 forum record, the prize tracks, and Part K, the experiment log with
  every measurement and its verdict.
* `build_notes.py` - rebuilds that PDF (`python docs/build_notes.py`; requires `reportlab`).
* `reorg.py`, `reorg_manifest.json`, `path_rewrites.json` - the repository reorganisation of 23 Sep 2026: what moved where,
  and which script paths were rewritten.
* `reference/` - captures of the challenge pages and the ARC research paper, kept so that the numbers quoted in the handbook
  remain checkable offline.
