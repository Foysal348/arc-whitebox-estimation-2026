One falsifier: test the stated transport model without an inverse
Derived consistency condition. There is a conflict between two stated premises. If a particular source
obeys P₊=MP and A₊=MA with the same M, then any exact relation A=PR is preserved: A₊=P₊R. If P and M
are invertible, P₊⁻¹A₊=P⁻¹A exactly. Therefore a 100-970% change in numerically computed P⁻¹A does not,
by itself, establish a changing right factor. An ill-conditioned inverse, source misalignment, a change of
coordinates, or an unrecorded update can produce that observation.
I still charge A’s transport. Even if this invariant holds, evaluating A₊=P₊R is another dense multiplication,
so it does not yield the requested saving. The issue matters because a no-go statement must specify the
actual computation it covers.
Measure. Select one matched birth at age 2→3, away from the join, and capture both legs immediately
before and after the same transport. Preserve birth identity and coordinate conventions. Use float64
products on the captured float32 values; compute
M  = W.astype(np.float64) * phi[None, :]
P0 = P_before.astype(np.float64)
A0 = A_before.astype(np.float64)
P1 = P_after.astype(np.float64)
A1 = A_after.astype(np.float64)
RP, RA = P1 - M @ P0, A1 - M @ A0
rhoP = np.sqrt(np.sum(RP * RP) / np.sum(P1 * P1))
rhoA = np.sqrt(np.sum(RA * RA) / np.sum(A1 * A1))
Interpretation. If ρ_A substantially exceeds the transport’s forward-roundoff scale while ρ_P does not, the
stipulated same-left-multiplication model is false for A at that capture boundary; an innovation or
unmatched convention must be included, and the certificate above does not describe that graph. If both
residuals are at roundoff scale, the inverse-based drift does not refute exact common transport. Establish
the roundoff scale by replaying the same operation, rather than using a universal fixed tolerance.
Exact diagnostic cost. For the shown algorithm, treating sqrt/division as one arithmetic operation each
and charging float64 twice, the arithmetic is 4g+22n² = 8,608,808,960 FLOPs = 4.0087890625 u. Casts
and copies are excluded under the stated arithmetic model. It uses two classical 1024-square products and
O(n²) storage; one stored transition should take well under an hour on a CPU that runs the benchmark.
This is a falsifier of the model underlying the conditional bound, not a test of a secretly proposed 55 u
algorithm. No such algorithm has been supplied here. Your leaderboard result demonstrates a cheaper
successful estimator, but does not establish that the gain is achievable by changing only ages 1-4 while
freezing the rest of V29.
