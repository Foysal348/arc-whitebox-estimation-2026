The single candidate: a pair core carried from the first ReLU
Keep a symmetric dense matrix G and a dense propagator Ul, each n by n [D]. Use the chain's existing first
post-ReLU pair slices as the birth:
 G_aa = k4(h_1)_aaaa
G_ab = 3 K22(h_1)_ab   (a != b)
U_2 = W_1;   U_(l+1) = U_l D_l W_l
D_l = diag(Phi(mu_l / sigma_l))
Later births are zero by definition. The slopes come from the baseline chain. Thus this is an explicit
approximation with long memory, not an exact cumulant update through ReLU. Under your row-vector
convention, Ul maps the first post-ReLU coordinates to pre-activation layer l.
 F_l(v) = ((U_l v) * (U_l v)).T G ((U_l v) * (U_l v))
S_l = U_l * U_l;   V_l = G S_l
k4hat_l = colsum(S_l * V_l)
Here * means elementwise multiplication. At birth, the coefficient of va2vb2 is 2Gab = 6K22ab [D], which fixes the
normalization. After dense transport, expanding F produces mixed monomials vavbvcvd with all indices distinct. G
is unrestricted and dense; this is neither diagonal-only transport nor a covariance scale-mixture. It does discard
other first-birth sectors and all subsequent nonlinear replenishment.
How it would enter the existing mean closure
It would replace the regenerated pre-activation diagonal in the existing Edgeworth term. Holding the other
channels fixed, with alpha = mu/sigma:
 delta mean_i = phi(alpha_i) (alpha_i^2 - 1)
               * (k4hat_i - k4regen_i) / (24 sigma_i^3)
This is the linear fourth-cumulant contribution [D]. The probe tested the auxiliary carrier only; it did not feed its failed prediction back
into the means or covariance.

Why long memory does not imply the requested correlation
The exact one-step carry oracle starts from the true, continually replenished tensor. This candidate starts from a
restricted birth and thereafter uses only linearized transport. The oracle therefore cannot establish its accuracy.
Adding arbitrary later births into this same G is not an exact closure; keeping separate propagated births changes
this cost ledger.
Parity correction [D]: with an upstream tensor fixed, a fourth-order contraction contains four factors of the
current W and is even under W to -W. The odd-parity argument for carried third cumulants cannot be applied
unchanged to fourth cumulants. The prompt's empirical failure of cheap even-statistic predictors [Q] remains
evidence, but is not such a parity theorem.

What this establishes
I reject this single mechanism. It demonstrates that a cheap, full-depth object with genuine all-distinct entries can
still lose the needed memory because the birth rule and nonlinear evolution are inadequate. It does not prove
that every inexpensive nonlinear state is impossible. I cannot justify a qualifying replacement from the available
evidence, and I will not claim the requested correlation without a passing falsifier.
