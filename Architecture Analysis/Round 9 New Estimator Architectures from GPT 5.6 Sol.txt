1. What the error map forces an architecture to do
 The mean formula is not the problem. A new design should spend essentially no research budget on a new marginal 
ReLU mean closure.
 The all-distinct post-ReLU K3 field must be created at the ReLU where it is born. A representation that first collapses 
it to repeated-index stars and hopes future linear mixing recreates it is structurally misaligned with the measured 
error.
 K4 cannot be a scalar regeneration law. The missing pattern is a fresh connected four-vertex field, especially 
(2,1,1)/(1,1,1,1), but it is only needed after contraction with the next weight row.
 The coefficient paradox is a warning against adding one Edgeworth family in isolation. Any new architecture should 
carry a coupled set of diagrams or a renormalized object in which partner terms are generated automatically.
 The new cost must be independent of the number of birth layers. The 116 u young tier and 107 u old tier cannot both 
survive.
A useful change of viewpoint
For a symmetric cubic tensor K and a query matrix Q, define the two-leg contracted response
H_Q(K)[i,p] = sum_{j,k} K[i,j,k] Q[j,p] Q[k,p].
If Q is the next weight matrix W, the next pre-activation (2,1) slice is obtained without reconstructing K:

2.2 The dressed cubic field
For the post-ReLU layer let E be the exact bivariate covariance returned by the bivariate closure. Let a_i = w(1,1)_i and 
b_i = w(2,1)_i. The weak-correlation Gaussian tree has the familiar center-leaf form b_i a_j a_k C_ij C_ik + permutations. 
Instead of using the bare edge a_i a_j C_ij, DHMP uses the exact bivariate edge E_ij and preserves the same weak-
correlation limit with
tau_i = b_i / max(a_i^2, eps).
The all-distinct cubic skeleton is
K3_tree(i,j,k) = tau_i E_ij E_ik + tau_j E_ji E_jk + tau_k E_ki E_kj,   for distinct i,j,k.
This is not a low-rank tensor approximation. It is a connected-tree graphical closure with n^2 edge degrees of freedom. 
Higher Hermite ladders in each pair are already resummed inside E.
For Q = W_next, define
R = E Q
X = (diag(tau) Q) elementwise* R
H_tree = diag(tau) (R elementwise* R) + 2 E X
D21_tree_next = H_tree^T Q.
Three dense products produce the all-distinct tree contraction for all n next-layer neurons at once: E Q, E X, and 
H_tree^T Q.

repeated planes. Therefore DHMP uses the tree model only for the all-distinct sector and adds an exact repeated-plane 
correction.

The important architectural rule is that the K3 x C pair is evaluated together with the dressed-edge tree field below. Do 
not scan its coefficient in isolation in production.
2.5 K4 diagonal from the same graph messages
The ARC factor-K4 implementation organizes the fresh all-distinct fourth-order field into connected path, star and 3+2 
hypertrees. That is exactly the structure needed here: contract the graph with Q four times; never build K4(i,j,k,l).
With c_i = w(3,1)_i and sigma_i = c_i/max(a_i^3,eps), reuse R=EQ. The dressed Gaussian star is
k4_star[p] = 4 sum_i sigma_i Q[i,p] R[i,p]^3.     (no dense product)
For the path graphs, the two degree-2 vertices carry tau. Set
P = (diag(tau) Q) elementwise* R,    Y = E P,

This adds one dense product E P for all outputs. The K3 x C 3+2 graph uses the already available cubic two-leg response 
H and R; its final contraction is a columnwise dot product after the appropriate Wick ratio is applied at the shared 
vertex. The coefficient is 12 in the ARC graph enumeration. Pairwise K4 level terms (K4 diagonal + K22/K31) are retained 
exactly; the K22 term requires one dense product against Q elementwise^2.
2.6 The item-6 paradox: what the missing partner probably is
The strongest explanation is diagrammatic double counting. The theoretical K3 x C coefficient is a coefficient in a bare 
expansion whose two-point edge is a_i a_j C_ij. But your actual chain already uses a near-exact bivariate ReLU closure, so 
the physical edge is dressed:
E = G + DeltaE,    G_ij = a_i a_j C_ij.
A dressed cubic tree contains
tau_i E_ij E_ik = tau_i G_ij G_ik + tau_i(G_ij DeltaE_ik + DeltaE_ij G_ik) + tau_i DeltaE_ij DeltaE_ik.
The second line is a deterministic partner correction. If it is omitted while the bare K3 x C coefficient is restored to its 
formal value, the update can over-shoot. The shipped half-strength coefficient can then be an accidental counterterm. 
DHMP includes the partner automatically because its edge is E, not G.

3. Architecture 2 - Finite-Horizon Query Response (FHQR-2)
Status: second recommendation. More state than DHMP, but it preserves young cubic memory in the exact query 
directions that will actually be used.
3.1 Why this is different from the adjoint/source approaches already killed
A per-source adjoint still pays one contraction for every source-layer pair. FHQR performs the sum over sources first. It 
stores global contractions of the entire cubic tensor against known future queries. The state count depends on a short 
horizon h, not on the number of births.
3.2 State and backward query pass
After a cheap forward pass supplies the derivative diagonals a_l=w(1,1), construct tangent queries backward. For h=2, 
keep
Q_l^(1) = W_{l+1}
Q_l^(2) = W_{l+1} diag(a_{l+1}) W_{l+2}        (orientation adjusted to the implementation convention).
The forward high-order state is two n x n response matrices
H_l^(t)[i,p] = sum_{j,k} K3_post_l[i,j,k] Q_l^(t)[j,p] Q_l^(t)[k,p],   t=1,2.
For h=2 this is two global matrices, regardless of how many birth layers contributed to K3.
3.3 Propagation rule
6. Linear shift: because Q_l^(2) already contains the next tangent map, the linearly transported old cubic content 
needed one layer later is obtained from H_l^(2) by a first-leg multiplication with W_{l+1}; no A_b/P_b legs are 
transported.
7. Nonlinearity: multiply the old response by the appropriate ReLU first-derivative factors and add the fresh dressed-
tree birth directly in each query Q^(t). The fresh term uses the same two products E Q and E((tau Q)*R) as DHMP.
8. Readout: D21_{l+1} is H_l^(1)^T W_{l+1} plus the exact repeated-plane correction. The K4 3+2 term reuses H_l^(1); 
the Gaussian K4 path/star use the same E Q message.
9. Horizon tail: information older than h steps is not dropped. It is closed by the DHMP dressed tree operator. Thus h 
controls how much non-Gaussian memory is exact in query space, while the tail has constant cost.

4. Architecture 3 - Quadratic-Chaos Galerkin (QCG)
Status: high-risk research architecture. It is attractive because K3 and K4 are generated by one common stochastic 
state, so inconsistent coefficient patches disappear. I would run only its falsifier before implementation work.
4.1 Idea
Write each centered neuron as a truncated Wiener-Hermite field rather than as cumulants born at layers:
h_i - E[h_i] ~= u_i^T xi + (xi^T H_i xi - tr(H_i)).
A quadratic Gaussian field automatically produces covariance, third cumulants and fourth cumulants through 
contractions of the same u_i and H_i. The architecture therefore cannot independently mis-tune a K3 x C family without 
also changing the partner quartic terms; this is exactly the consistency missing in item 6.
4.2 Compressed Galerkin state
The impossible version stores one full H_i per neuron (O(n^3) state). The testable version uses a moving common 
quadratic basis B with n modes and stores only coefficient matrix S:
H_i ~= sum_r S[i,r] b_r b_r^T,     B = [b_1 ... b_n].

State: U (n x n first-chaos map), B (n x n quadratic basis), S (n x n coefficients), plus mean. This is O(n^2) memory. A 
linear layer mixes rows of U and S. A ReLU adds a local rank-one quadratic birth proportional to w(2,1)_i u_i u_i^T, then 
the quadratic field is projected back into the moving B basis.
4.3 Cost and the dangerous step
A practical implementation would spend roughly 6-9 dense products per transition: first-chaos transport, coefficient 
mixing, one overlap/rebasis product, and 3-6 Gram contractions to obtain covariance/K3/K4. That is roughly 105-150 
u/network conventionally including closure, or 60-90 u at the stated L5 price.
The dangerous step is the re-basis projection. A fresh square (u_i^T xi)^2 creates cross terms in a generic basis. If the off-
diagonal quadratic-core energy is not small, the required basis dimension grows to n(n+1)/2 and the architecture 
collapses back to an impossible state. This is why QCG is third, not first.
