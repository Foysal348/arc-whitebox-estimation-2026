Why querying 350 variances does not close the state
Once C_post is known, m quadratic forms cost one C_postW_m product plus column dot products:
m/n≈0.342 u at m=350. V29 still needs C for births and other closures, so this is not automatically a saving.

A first version with no new source contractions

What this approximation loses
F is not the full fourth cumulant of even the truncated polynomial. It omits cycles, higher marginal Hermite
orders, input K5/K6, and additional K4×C and K3² terms. For Gaussian L+Q alone, the exact additional ring
is 3 tr[(C diag b)⁴]. A generic evaluation costs O(n³) per query, so it cannot be called free. Weak off-diagonal
correlations justify a diagram ordering for distinct indices, not a uniform 2% guarantee, especially for
repeated indices.
The next page matches reliable repeated-index slices exactly within the surrogate. The appendix gives the
leading repeated-index law and inexpensive harmonic K4×C contractions. All accuracy claims beyond the
derived terms are conjectures.

6 / Sampling corrections: subtracting a constant is not a CV
Derived. For y=z−μ, the centered influence functions for the three cumulants are
Estimating δv as a sample variance minus the chain value leaves the sampling variance unchanged. A
usable estimator is an unbiased sample cumulant minus the chain estimate minus β times the sample
mean of a zero-mean Gaussian Hermite control; fit β on an independent split. Its leading noise is governed
by these influence functions. Near Gaussianity their variances are (2v², 6v³, 24v⁴). Raw moments up to
eight, or paired samples, are needed to assess non-Gaussian fourth-cumulant estimator noise accurately.
For a jointly Gaussian standardized target and surrogate with correlation ρ, Hermite orthogonality gives
Corr(H_q(Z),H_q(G))=ρ^q. Optimal control reduces variance by 1−ρ2q. A 100× reduction needs
|ρ|≥0.99749, 0.99833 and 0.99874 for q=2,3,4 respectively. Similar marginal distributions or accurate
analytic moments do not establish such a samplewise coupling.

Appendix C / Minimal NumPy diagnostics
All arrays below use ordinary cumulants, not the reference program’s rescaled Wick buffers. W has columns
as output queries. The first routine costs O(n²); the second costs two n×n by n×m products. Matching the
known slices is specified on page 5.
import numpy as np
def teacher_cov_noise(Cpost, K22post, N=60_000_000):
    v = np.diag(Cpost)
    # Leading variance, not a noise-corrected residual by itself.
    return (K22post + v[:,None]*v[None,:] + Cpost*Cpost)/N
def missing_cov_terms(C, d2, d3, d4, K31):
    C = C.copy()
    np.fill_diagonal(C, 0)
    C2 = C*C
    out = (C2*C)*(d3[:,None]*d3[None,:])/6
    out += (C2*C2)*(d4[:,None]*d4[None,:])/24
    B = d4[:,None]*K31*d2[None,:]
    out += C*(B+B.T)/6
    return out
def project_variance(E, W):
    return np.sum(W*(E@W), axis=0)
def quartic_kernel(C, W, d1, d2, d3, g, lam, metric):
    u = d1[:,None]*W
    b = d2[:,None]*W
    c = d3[:,None]*W
    q = C@u
    t = b*q
    r = C@t
    h = lam*q + (g-lam*np.diag(C))[:,None]*u
    f = metric*np.sum(u*u,axis=0)*np.sum(u*h,axis=0)
    f += 4*np.sum(c*q*q*q,axis=0)
    f += 12*np.sum(t*r,axis=0)
    return f

implemented mean program when ranking neurons.

Scope of verification
The Gaussian covariance terms and wk431 extension were checked in the available public V29 source. A
small independent NumPy program checked the quartic polynomial, its gradient, local pair slices and the
factored K3 contraction. Its largest reported pair-matching discrepancy was 1.1×10⁻¹⁴. No teacher arrays,
teacher sample blocks or raw input/output sample pairs were supplied for Round 7. Therefore every
proposed network-accuracy improvement remains a falsifiable hypothesis.
Practical implementation boundaries
All persistent state proposed here is O(n²) in addition to the existing K3 source representation. O(nm) query
work can be blocked to stay well below the memory cap. Dense-product estimates include the stated
Strassen cost only for square products; shared source-basis and rectangular query products use explicit
classical counts. Gaussian CDF/PDF and Wick coefficients are reused from the existing closure. Additional
source thin legs, conversion conventions and any fallback factorizations must be counted by the shipping
meter.
A first falsifier is a local negative test, not a proof of final accuracy. A local pass must be followed by the
prescribed end-to-end comparison; a failure closes that approximation without reviving previously failed
rank, age-window or sampling proposals.
