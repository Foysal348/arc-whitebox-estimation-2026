No: sum-of-sources is not the only formulation. It is one representation of a particular cumulant
recurrence. Other methods integrate the network function, represent its input-space dependence,
optimize over admissible probability laws, or perform global approximate inference. None of the sources

1 / Integrate Gaussian activation regions
Derived; geometric tools exist [2,3]. Carry cones Rπ and linear maps Aπ, so fW(x)=Aπx on each
activation region. Then
Update/state. At a layer, form WAπ, split each cone by its n sign inequalities, and zero inactive rows.
Storage is O(Rn²) map entries plus facets. The dense map update alone costs Rn²(2n−1)/2³¹≈R u/layer;
Gaussian cone moments are additional. Fixed signed weights enter every region and slope, so no odd
information is ensemble-averaged away.
Cost obstruction. The first square Gaussian weight matrix is invertible almost surely, so all 21024
first-layer sign cones are nonempty. This rejects explicit full enumeration, not implicit geometric
integration. Holonomic Gaussian integration replaces integrals with differential equations, but its state
depends on the polyhedron’s face structure [3].
A cheaper geometric subproblem, actually tested
Restrict x=y+tv with y⊥v. Store intervals and vector slopes/intercepts f(y+tv)=art+br. Update the two
coefficient matrices by W, then split at roots. An interval contributes exactly
FLOPs. Two n×n by n×R products cost ≈2R/n u/layer in float32, twice that in float64, plus splitting.
State: 2nR floats. This is analytic integration across every gate on the chosen line, not a new name for
point sampling.

2 / Project the network function in input space
Derived; polynomial-chaos machinery [4]. Carry Hiα for hi(x)≈∑α∈ΛHiαΨα(x), where Ψ are
Gaussian-orthonormal Hermite polynomials. The mean is Hi0. Linear mixing is exact within the retained
function space:
State/cost. With P basis functions, state size is nP. The linear update costs nP(2n−1)/2³¹≈P/n u/layer.
Evaluating and projecting on S quadrature nodes adds approximately 2PS/n² u/layer, plus basis
construction. The nonlinear projection is not free.
Full degree two already has P=binom(1026,2)=525,825: 2.006 GiB per coefficient state and 513.25 u
per linear update. Even tiling with the supplied Strassen rate is around 262 u. Thus the straightforward
dense method fails before its nonlinear integration is priced.
What differs from the dead Hermite proposal. This represents the input-to-activation function, not
diagonal quadratic coordinates of an old K3 query. Its errors come from omitted input interactions and
numerical projection. The previous D21 spectra do not measure these coefficients.
First falsifier, under 0.01 u. For the cheap diagonal-quadratic variant, the retained fraction of a
first-layer neuron’s second-chaos energy is ∑jwj4/(∑jwj2)². On the same network it averaged 0.2926%.
This rejects a claim of faithful diagonal-quadratic function representation; it is not a lower bound on
final-mean error. Adaptive bases remain a different, unpriced approximation until their projection step is
specified.
3 / Tensorize the input integral, not K3
Derived; adaptive tensor quadrature exists [5]. On a product quadrature grid, represent each
scalar output as
then integrate each core with its one-dimensional weights. Rank χ, q nodes and separate cores for all n
outputs require O(n²qχ²) entries: about 32 MiB at q=2, χ=2. Cross updates request selected full-network
values and update cores. There is no layerwise cumulant update.
These tensor axes are input coordinates, not the three neuron indices of K3. Therefore the measured
old-core TT rank≈250 is not a rank measurement of this object. The price is the network-evaluation
budget, interpolation bias, and product-quadrature bias.

Function-space TT: a plausible bill is not enough
Conjectural cost gate. One fixed-rank pass using shared cross locations for all outputs requests
roughly N=nqχ² full forward evaluations. A forward pass costs exactly L/n=1/64 u including ReLUs, so the
pass costs Lqχ² u classically. Fully batching those requests permits the optimistic 0.51 multiplier on
dense products.
At q=2, χ=2: 128 u/pass classically, approximately 65.3 u/pass with ideal batching. Two passes plus
small-core arithmetic are roughly 132 u. This is a conditional ledger, not the measured cost of an
implemented solver: common pivots, stable tiny inverses and two-pass convergence are assumptions.
Output-specific query sets or extra passes invalidate it. At q=4 or χ=4 the analogous two-pass product
bill is already about 261 u or 522 u.
Additional bias. Two-node Gauss–Hermite quadrature integrates Rademacher inputs, not Gaussian
inputs. Multiplying by E‖X‖/√n=0.999755889 corrects the radius for a homogeneous network, but not the
angular distribution. This unresolved bias must also be measured; a low TT rank would not settle it.

4 / Optimize over the entire joint probability law
Derived application of moment/SOS methods [6]. Introduce all variables z=(x,h¹,…,h¹⁶). ReLU is
characterized by polynomial constraints h≥0, h−Whprev≥0 and h∘(h−Whprev)=0. Fix input moments to
their Gaussian values and bound E[h¹⁶i] using positive-semidefinite moment and localizing matrices.
State/update. This is a global optimization problem, not a forward chain. Increasing the relaxation order
adds moment variables and constraints; an SDP solver updates them together. Signed W enters the
constraints. This differs from truncating a forward cumulant recurrence, although both use moments.
FLOPs. The first moment matrix already has dimension d=17n+1=17,409 and occupies 1.129 GiB in
float32. A single conventional dense Cholesky factorization costs d³/3≈819 u; an SDP solve requires
more. Sparse formulations change that ledger, but must separately establish tight bounds.
First falsifier, <0.01 u. For just Y=ReLU(Z), Z∼N(0,σ²), the elementary degree-two moment relaxation
permits 0≤E[Y]≤σ/2, whereas the exact mean is σ/√(2π). Thus its cheapest local version is far too loose
already at layer one. This rejects that relaxation order, not the full hierarchy.
5 / Certified expectation bounds with branching
Derived adaptation of probabilistic verification [7]. Carry Gaussian input cells, their masses and
first moments, and affine lower/upper network envelopes. Split a cell, propagate tighter ReLU relaxations,
integrate the envelopes, then sum cell bounds. Alternatively integrate bounds on P(fi(X)>t) over t.
Gaussian tails must be included.
State/cost. Two n-output affine envelopes need about 2n² coefficients per active cell. Each backward
layer uses two n×n products: about 2 u/layer/cell, or 32 u per full-depth cell; ideal Strassen reduces
products toward 16.3 u. Branching, interval preparation, Gaussian masses and tails add cost. The
working budget therefore buys only a few such full-output cells.
First falsifier, <12 u for leading operations. On one network, use eight cells and 32 selected
outputs; backward products cost about 8 u, with roughly 0.5 u for interval passes. Bill all remaining work.
For midpoint estimates, a certificate requires RMS bound width ≤2√(2×10−8)=2.83×10−4. A wider gap
rejects that eight-cell configuration. Source benchmarks do not demonstrate this tolerance at 1024×16.

6 / Fixed-weight expectation-consistent inference
Literature/code-verified [8]. EP and ML-VAMP operate on known weight matrices; they are not merely
annealed formulas. Carry forward/backward Gaussian messages, update linear blocks by Gaussian
conditioning and nonlinear blocks by truncated-Gaussian moment projection. A typical linear update has
the form
State/cost. Scalar-variance messages require O(Ln) entries plus weights and matrix decompositions. A
four-matvec-per-layer sweep is about 4L/n=0.0625 u, excluding scalar updates. However, the inspected
SVD-based linear primitive requires decompositions: a standard full-vector square SVD costs about 13 u
under the inspected meter, or 208 u for 16 weights. Matrix-free variants need a different complete
ledger.
Why it is not a demonstrated solution. The cited theory concerns inference from observations and
large-system reconstruction error, not a 10−4-accurate prior mean on one fixed network. Without
observations, the elementary Gaussian-message forward construction reduces to Gaussian moment
propagation; bidirectional iteration alone does not create the missing information.
First falsifier, <1 u. Set the output likelihood to one and test the scalar ReLU site on actual-network
Gaussian marginals. In the code’s infinite-output-variance limit, the incoming Gaussian is unchanged and
the outgoing mean is μΦ(μ/σ)+σφ(μ/σ). If the proposed whole algorithm adds no non-Gaussian joint state
beyond these updates, your existing Gaussian-closure floor applies. Larger clusters or richer messages
are new approximations that still need pricing.
What not to count as another working algorithm
Derived. Fourier transforms, heat equations, path integrals, Koopman operators and tropical geometry
give useful equivalent representations. A representation becomes a computational proposal only after its
discretization, compression and mean readout are specified. For example, ReLU networks admit
differences of polytope support functions [9], but Minkowski sums and convex hulls can explode;
evaluating their Gaussian widths is the unresolved integration task.
The parity obstruction concerns predicting an odd preactivation tensor from even statistics. It does not
prohibit every fixed-W functional method or every even final-mean correction. Indeed
E[ReLU(Z)]=(E[Z]+E|Z|)/2, and the second term is even under a final-row sign flip.
Research conclusion
Alternatives exist; no target-budget winner was found. Full geometric enumeration, dense
polynomial chaos and dense moment optimization fail explicit cost gates. The cheap function-TT
configuration has adverse new evidence. Verification and message passing require substantially tighter
or richer approximations. The earlier table is not exhaustive, but neither this search nor those
measurements justify naming a hidden leader algorithm.

Why the scalar moment relaxation is loose
For σ=1, write m=E[Y] and s=E[Y²]=E[ZY]. PSD of the moment matrix for (1,Z,Y) requires s−m²−s²≥0.
Hence m≤1/2; m=0 and m=1/2 are feasible in this low-order relaxation. Positivity only at this relaxation
order does not enforce the full ReLU graph almost surely. Higher orders are essential, and expensive.

Appendix B / Reproduce the input-function rank probe
This code reproduces the finite-grid comparison from scratch. It is deliberately a cheap numerical gate for
a new representation, not a final estimator. It uses NumPy only; the geometric line test additionally used
SciPy’s standard normal CDF for interval integration.
import os
for key in ["OPENBLAS_NUM_THREADS", "OMP_NUM_THREADS",
            "MKL_NUM_THREADS"]:
    os.environ[key] = "1"
import numpy as np
n, L, m = 1024, 16, 16
rng = np.random.default_rng(22092026)
W = [rng.standard_normal((n,n), dtype=np.float32)
     * np.float32(np.sqrt(2/n)) for _ in range(L)]
U = rng.choice([-1., 1.], (n//2,m)).astype(np.float32)
V = rng.choice([-1., 1.], (n//2,m)).astype(np.float32)
X = np.concatenate([np.repeat(U,m,axis=1),
                    np.tile(V,(1,m))], axis=0)
for w in W:
    X = np.maximum(w @ X, 0)
Y = X.reshape(n,m,m)
A, s, Bt = np.linalg.svd(Y, full_matrices=False)
mu = Y.mean(axis=(1,2), dtype=np.float64)
for r in [1,2,4,8]:
    Yr = (A[:,:,:r] * s[:,None,:r]) @ Bt[:,:r,:]
    mur = Yr.mean(axis=(1,2), dtype=np.float64)
    print(r, np.mean((mur-mu)**2))

Reproduce the geometric update
Start with edges (−6,6), slope v/‖v‖ and intercept y orthogonal to v. For each layer: multiply all slopes
and intercepts by W; in each interval collect every root −bj/aj lying strictly inside it; sort the roots; copy
the parent coefficients into the new intervals; zero rows whose value at the interval midpoint is negative.
Integrate the resulting coefficients using the formula on page 2.
Count matrix products using their actual interval counts Rl−1: 4∑lnRl−1(2n−1) FLOPs in float64. The factor
four is two products times the float64 surcharge. This protocol is independent of SyReNN’s
implementation and does not assume its wall-clock performance.

How to read the evidence
The reference-chain correction comes from actual F51/F64 code documentation. VAMP’s linear/ReLU primitives were
inspected. SyReNN, tensor-cross, basis-adaptation and probabilistic-verification repositories were reviewed for scope and
algorithm descriptions. The executed experiments are independent NumPy diagnostics, not reproductions of their full
software benchmarks.
A failed finite-grid test, an expensive implementation, or a loose relaxation closes that configuration. It does not prove that
all methods in the corresponding mathematical family are impossible.
