Q4: Ranking and First Experiment
1. Run Q2 First ( κ4 diagonal): The algebraic factorization collapses an intractable tensor
into O(n) vector operations using matrices ( V ) the chain already computes. Marginal cost
is ≈ 0.01 units, it fixes ∼ 30% of the error , and provides a massive ∼ 3000% score gain per
unit compute.
2. Run Q1 Second (Variance Adjoint): Perfectly shares the Ms projection matrix with Q2,
yielding the exact 1-loop covariance correction for ∼ 0.05 units and fixing ∼ 47% of the
error .
3. Keep Q3 (Polynomial CV) as a backup: While 0.16 units is well within budget, it introduces
stochasticity. Given the harsh MSE scoring penalty, purely analytical methods (Q1/Q2)
strictly dominate sampling if the algebra closes, which it does.
